# Códigos de Flor - IA2 (Unidad 1)

Este directorio contiene las implementaciones de los algoritmos de búsqueda y optimización para el Trabajo Práctico 1.

### Algoritmos Implementados:
* **Búsqueda A* (`A_estrella.py`):** Resolución de rutas óptimas utilizando heurísticas.
* **Temple Simulado (`TempleSimulado.py`):** Algoritmo de optimización para la organización de la estantería.

### Archivos de Soporte:
* **`Nodo.py`:** Definición de la estructura de datos para los estados.
* **`Estanteria.py`:** Lógica del entorno y manejo de posiciones.
* **`ordenes.csv`:** Datos de entrada con los pedidos a procesar.

### Cómo ejecutar:
Los scripts principales para realizar las pruebas son `main1.py`, `main2.py` y `main3.py`.
